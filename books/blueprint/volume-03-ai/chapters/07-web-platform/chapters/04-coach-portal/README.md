# Coach Portal

> **Blueprint Module 7.4 — Web Platform**

The Coach Portal is the professional workspace of the EVOXA Platform.

It enables coaches, nutritionists, trainers and healthcare professionals to manage clients, monitor progress, create personalized programs and collaborate with EVO, the AI-native assistant.

Unlike the User Portal, which focuses on an individual user experience, the Coach Portal provides operational capabilities for managing multiple clients, teams and organizations.

---

## Objectives

The Coach Portal enables professionals to:

- Manage client portfolios.
- Create and assign training programs.
- Design personalized nutrition plans.
- Monitor Human Digital Twins.
- Communicate with clients.
- Schedule appointments.
- Analyze progress.
- Generate AI-assisted recommendations.
- Operate their professional business.
