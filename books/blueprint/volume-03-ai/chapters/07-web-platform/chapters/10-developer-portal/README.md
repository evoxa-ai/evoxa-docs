# Module 10 — Developer Portal

> **Developer Portal** is the central platform where developers, partners, integrators and enterprise customers build, extend and integrate solutions with the EVOXA ecosystem.

---

## Purpose

The Developer Portal provides every technical resource required to build applications on top of EVOXA.

It centralizes:

- API Documentation
- SDKs
- Authentication
- MCP Servers
- AI APIs
- Agent APIs
- Workflow APIs
- Webhooks
- Events
- CLI
- Examples
- Tutorials
- Developer Console
- Sandbox
- Marketplace

The platform follows an **API First**, **Developer First**, and **AI Native** philosophy.

---

# Objectives

The Developer Portal enables developers to:

- Build AI Applications
- Integrate Enterprise Systems
- Create Custom Agents
- Publish Plugins
- Consume APIs
- Build Workflows
- Deploy Extensions
- Manage Organizations
- Test Integrations
- Monitor Usage
