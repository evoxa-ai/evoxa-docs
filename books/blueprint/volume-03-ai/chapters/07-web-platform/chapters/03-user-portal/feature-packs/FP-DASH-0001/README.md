# Overview

The Dashboard is the primary workspace presented to authenticated users after login.

It consolidates personalized health information, AI recommendations, daily priorities and actionable insights into a single adaptive experience.

Rather than acting as a static homepage, the Dashboard dynamically adjusts its content according to the user's current health status, goals, context and behavior.

---

# Purpose

Provide users with immediate visibility into the information that matters most today.

The Dashboard should answer three questions within five seconds:

- What is my current health status?
- What should I do today?
- Why is it important?

---

# Objectives

The Dashboard shall:

- Present today's priorities.
- Display personalized recommendations.
- Provide one-click access to daily activities.
- Visualize long-term progress.
- Surface AI-generated insights.
- Encourage healthy habits.
- Reduce cognitive load.
