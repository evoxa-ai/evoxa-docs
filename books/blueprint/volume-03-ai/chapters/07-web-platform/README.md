# Overview

The EVOXA Web Platform is the primary web experience of the EVOXA ecosystem.

It provides specialized portals for every type of user while maintaining a unified user experience through a shared design system, platform services, security model, and AI capabilities.

Rather than multiple independent applications, the Web Platform is designed as a single modular ecosystem composed of role-specific portals.

---

# Objectives

The Web Platform aims to:

- Deliver a consistent user experience.
- Support all business domains.
- Provide AI-assisted workflows.
- Enable modular feature development.
- Ensure accessibility and responsiveness.
- Support enterprise scalability.
