## Overview

The Identity Platform is the centralized Identity and Access Management (IAM) solution for the EVOXA ecosystem.

It provides enterprise-grade authentication, authorization, federation, identity governance, machine identities, AI identities, Zero Trust security and multi-tenant access management.

The platform establishes a unified identity layer across all EVOXA products, enabling secure interactions between users, services, AI agents, APIs, workflows and external enterprise systems.
