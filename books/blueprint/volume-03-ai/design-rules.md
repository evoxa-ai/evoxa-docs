# Platform Design Rules

Every design document shall:

✔ be implementation-ready

✔ reference Blueprint chapters

✔ reference ESPs

✔ reference ADRs

✔ reference IS

✔ define permissions

✔ define APIs

✔ define events

✔ define UI

✔ define AI

✔ define business rules

✔ define analytics

✔ define observability

✔ define accessibility

✔ define security

✔ define future evolution

Documents shall avoid implementation-specific code and instead provide technology-agnostic design guidance unless the purpose of the document is explicitly implementation-focused.
